# Next.js Checkers Board

## 📌 Descrição
Este projeto exibe um tabuleiro de damas estilizado usando Next.js e Styled Components. O foco é apenas no layout visual, sem interatividade.

## 🛠️ Pré-requisitos
Antes de rodar o projeto, verifique se você tem as dependências instaladas.

### Verificar instalação do Next.js e Styled Components
Execute o seguinte comando no terminal:
```sh
npm list next styled-components
```
Se ambos os pacotes aparecerem na lista, siga para a execução do projeto.

Caso algum deles não esteja instalado, execute:
```sh
npm install next react react-dom styled-components
```

## 🚀 Como rodar o projeto
```sh
git clone https://github.com/seu-usuario/dama-app.git
cd dama-app
npm install
npm run dev
```

## 🎨 Estilização
- O tabuleiro é criado dinamicamente com Styled Components.
- Peças são círculos coloridos posicionados nas casas corretas.
- Há um efeito hover nas casas para melhor experiência visual.
