# 🧠 Calculadora Demente

Uma calculadora feita em **Next.js** com um **modo insano de operação**. 
Perfeita para quem está cansado da matemática tradicional e quer dar um toque de caos nos cálculos do dia a dia.

## 🚀 Funcionalidades

- ✅ Operações básicas: adição, subtração, multiplicação e divisão
- ✅ Visor com operação em andamento
- ✅ Botões de memória: `M+`, `M-`, `MR`, `MC`
- ✅ Estilo dark futurista com fontes retrô
- ✅ **Modo Demente™** com as seguintes regras:
  - ➕ vira ✖️
  - ➖ vira ➕
  - ✖️ vira ➗
  - ➗ vira ➖
- ✅ Toggle com tooltip explicativo
- ✅ Letreiro neon piscante dizendo “clica aqui logo”

## 🖥️ Rodando localmente

1. Clone o projeto:

    git clone https://github.com/Rogeriokjah/Prog-Scripts-FATEC/tree/calculadora-demente-final
    cd calculadora

2. Instale as dependências:
    npm install

3. Inicie o servidor local:
    npm run dev

Acesse em: http://localhost:3000


🧪 Estrutura dos componentes
- Display.js: mostra o valor atual e a operação em curso
- Keypad.js: grade com todos os botões
- Button.js: botão genérico estilizado
- index.js: lógica principal da calculadora
- Home.module.css: estilo dark e psicodélico
